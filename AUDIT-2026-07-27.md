## 2. Body text: PASS with 5 items to resolve

Normalizing for punctuation, dashes, case, and compound-word spacing, 23 of 36 entries show
word-level differences. Eighteen are intentional or cosmetic. Five need a decision.

### 2a. Intentional and correct: 24-hour run figures moved to `conditions`

Fourteen entries have the `24-hour run — NNN miles` sentence removed from `body` and restated
in `conditions`. This is correct per the established convention. Verified present in
`conditions` for every affected entry. No action needed.

One nuance: on **2003-05-21** more than the run figure was moved. The full trailing sentence
("Wind 20 knots, seas 3 meter swell, maintaining 5 knots to windward still — Charlotte can
handle this") went to `conditions`, and the phrase "Charlotte can handle this" was dropped
entirely rather than relocated. That line is voice, not data. Recommend restoring it to `body`.

### 2b. Cosmetic normalizations, no action needed

`3pm → 3 pm`, `4am → 4 am`, `8pm → 8 pm`, `1pm → 1 pm`, `6am → 6 am`, `DVD's → DVDs`,
`rainwater → rain water`, `staysail → stay sail`, `headwinds → head winds`,
`motor sailing → motorsailing`, `sevu-sevu → sevusevu`.

Note the pairs are inconsistent in direction: the JSON splits `staysail` and `headwinds` into
two words but joins `motorsailing` and `sevusevu`. Worth picking one convention. `staysail`
and `headwind` are the standard single-word nautical forms.

## Post-regeneration open items

Three judgment calls I did not make on your behalf.

**1. 2003-05-21 — text now duplicated in `body` and `conditions`.**
The draft's closing line is "24-hr run 120 miles. Wind 20 knots, seas 3 meter swell, maintaining
5 knots to windward still — Charlotte can handle this!" Only the run figure was stripped, so the
wind/sea sentence is now in `body` and also in `conditions`. Options: drop it from `conditions`
and let `body` carry it (keeps the voice, loses the structured data), or trim `body` back to
"...Charlotte can handle this!" and leave the measurements in `conditions` only.

**2. Time formats reverted to the handwriting.**
The old JSON had normalized `3pm → 3 pm`, `8pm → 8 pm`, `1pm`, `4am`, `6am`. The draft has them
closed up, so the regen restored the closed form on 7 entries. This is faithful to the original
but inconsistent with legs 01–04, which use the spaced form. Say the word and I will apply a
normalization pass across all legs either direction.

**3. 2003-05-20 — possible remaining transcription gap.**
The draft reads "It was nice to talk to someone else, knew after being alone out here for a
week." That sentence is grammatically incomplete. The old JSON had "someone else, we knew after",
which is also odd. Likely the handwriting is something like "you know" or a phrase not yet
resolved. Worth a look at the scan; the JSON currently matches the draft exactly.

**Applied without asking:** en-dash restored on 7 numeric ranges (`6-8 → 6–8`, `25-30 → 25–30`,
etc.). Legs 02–04 use en-dash for ranges in 31 of 31 instances, so this was existing convention
rather than a new choice.

**Not from this regeneration:** `git diff` also shows `leg-01`, `leg-02` and `photo-albums.json`
as modified. Those were already uncommitted before this session (re-minification from the photo
